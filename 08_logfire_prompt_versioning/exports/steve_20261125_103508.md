Steve, to learn Python and become a data engineer:

1. Study Python fundamentals (syntax, data structures, file I/O, testing) for 4–6 weeks.
2. Add SQL (joins, window functions), pandas, APIs, Git, and cloud basics (AWS recommended).
3. Build end-to-end ETL pipeline projects (extract from API, transform with pandas/PySpark, load to database/warehouse, schedule with Airflow) and publish on GitHub.
4. Focus on data engineering, not data science—skip heavy ML/stats.
5. Resume: highlight Python, SQL, cloud, orchestration; quantify results.
6. Target Junior Data Engineer / ETL Developer roles; expect 6–9 months part-time.
7. Practice SQL and Python scripting daily for interviews.

Start with a small project this weekend: pull API data, clean it, save it somewhere, and share it on GitHub.
