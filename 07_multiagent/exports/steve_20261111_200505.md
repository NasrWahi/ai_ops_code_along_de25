Steve, here is your roadmap to learn Python and become a data engineer:

**What to study:**
1. Python fundamentals — data structures, functions, classes, error handling, virtual environments, and Git.
2. Python for data — pandas, requests (APIs), SQL, and pytest.
3. Data engineering tools — Airflow, dbt, Docker, and one cloud platform (AWS, Azure, or GCP).
4. Data warehousing — Snowflake, BigQuery, or Redshift.

**Build 3 portfolio projects:**
- API → Python/pandas → SQL database ETL pipeline, scheduled with Airflow.
- Data lake medallion (raw → silver → gold layers) in cloud storage.
- Change data capture or streaming pipeline.

**Career path:** Junior Data Engineer → Data Engineer → Senior Data Engineer. Target roles like Junior Data Engineer, ETL Developer, or Analytics Engineer. Expect 6–12 months of part-time study.

**Key advice:** Focus on building and shipping real pipelines, not just watching tutorials. Put your code on GitHub with clear READMEs.
